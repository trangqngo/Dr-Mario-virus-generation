# Dr. Mario Virus Generation

Official implementation for analyzing and generating virus grid configurations in the classic Nintendo game **Dr. Mario**. 

This repository contains algorithmic tools and experimental scripts for analyzing the theory, practice, and procedural generation of virus layouts for the Nintendo Famicom/NES and Game Boy systems.
